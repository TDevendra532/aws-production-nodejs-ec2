# Diagrams

This directory contains the architecture diagrams.

## Files

- `D1_architecture.png` — main architecture diagram (PNG export, 300 DPI)
- `D1_architecture.drawio` — editable source (open in [draw.io](https://app.diagrams.net))

## How to update

1. Open `D1_architecture.drawio` in draw.io
2. Make edits
3. Export as PNG (300 DPI) and overwrite `D1_architecture.png`
4. Commit both files

## Note

PNG is the authoritative version for review. The drawio source is committed alongside so the diagram can be modified later without losing the structure.
